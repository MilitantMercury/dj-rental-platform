# Security Policy

## Versioni supportate

| Versione | Supportata |
| --- | --- |
| 1.0.x | Sì |
| < 1.0 | No |

Gli aggiornamenti di sicurezza vengono applicati alla versione stabile corrente. Le versioni precedenti alla `1.0.0` erano build di sviluppo e non ricevono correzioni separate.

## Segnalare una vulnerabilità

Non aprire issue pubbliche contenenti vulnerabilità, credenziali, dati personali o istruzioni di sfruttamento.

Usa la funzione **Report a vulnerability** nella sezione **Security** del repository GitHub. La segnalazione dovrebbe includere:

- componente e versione interessati;
- passaggi minimi per riprodurre il problema;
- impatto osservato o potenziale;
- eventuale correzione proposta, senza includere segreti reali.

La segnalazione viene verificata in forma privata. Se confermata, la correzione viene preparata e pubblicata prima della divulgazione dei dettagli. Chiavi, token o password eventualmente esposti devono essere revocati immediatamente e non inseriti nella segnalazione.
